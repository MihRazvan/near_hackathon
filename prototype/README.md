# Everywhere — product experience prototype

An isolated, local website for reviewing the advertising marketplace before final design. **Everywhere is a working name.** All records, vehicle illustrations, authentication, transactions, AI outputs and analytics are sample values. This app does not connect to wallets or the technical proof server.

```sh
cd prototype
npm ci --ignore-scripts
npm run dev
```

Open **http://localhost:4173**. Production files are generated by `npm run build`. Vite serves only this prototype directory.

The top review bar switches sample personas and populated/empty/loading/error states. **All screens** opens the complete destination index. **Reset** restores the starting story. **Demo controls** advance the sample campaign calendar or save page-specific feedback; the index exports review notes as JSON.

First increment: shared visual components, coherent sample records, route index, public marketplace, vehicle/spot page, filters, owner profiles, help and policy views. The index explicitly identifies workspace destinations being assembled in subsequent feature increments.

The approved direction and complete screen inventory are recorded in `docs/product/` at the repository root. The review-window duration in sample dates is illustrative; it is not an agreed commercial policy.
